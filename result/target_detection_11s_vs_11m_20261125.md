# Gazebo 과녁 탐지 비교: YOLO11s와 YOLO11m

## 시험 조건

- 2026-11-25, 기존 `run_target_detection.sh`의 같은 월드와 기체 경로를 각각 한 번 실행했다.
- 카메라 3200×3200 RGB에서 중앙 1280×1280 crop, 입력 크기 `imgsz=1280`, confidence 기준 0.15, 출발 과녁 거리 100m, 과녁 크기 2×2m.
- WSL 가상환경의 Gazebo protobuf 호환을 위해 두 실행 모두 `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python`을 적용했다.
- 측정 대상은 `.pt` 체크포인트다. Hailo-8 HEF의 INT8 정확도나 장치 FPS를 측정한 결과가 아니다.

| 지표 | YOLO11s (`hef_11s/best_11s.pt`) | YOLO11m (`YOLO11m_best.pt`) |
| --- | ---: | ---: |
| 최초 과녁 겹침 탐지 거리 | **94.03m** | 89.11m |
| 최초 탐지 시뮬레이션 시각 | 2.006초 | 2.992초 |
| 최초 탐지 신뢰도 | 0.5277 | 0.8681 |
| 카메라 프레임이 있는 시뮬레이션 초 | 16 | 16 |
| 그중 표적을 탐지한 초 | 12 | 12 |
| 표적 탐지 초의 최고 신뢰도 평균 | 0.7177 | 0.8947 |
| 처리된 프레임 | 27 | 26 |

CSV 원본: [YOLO11s](target_detection_20261125_141006.csv), [YOLO11m](target_detection_20261125_141109.csv). 최초 탐지 신뢰도와 시각은 각 실행의 콘솔 출력에서 기록했다.

## 해석 범위

이 두 실행에서는 11s의 **기록된 최초 탐지 거리**가 4.92m 더 멀었다. 반면 같은 초에 기록된 최고 confidence는 대체로 11m이 높았다. 프레임 처리 수와 프레임 시점이 완전히 같지 않고 모델당 한 번씩 실행했으므로, 4.92m 차이를 모델의 재현 가능한 탐지 우위로 해석할 수는 없다. 같은 저장 프레임에 두 모델을 적용하거나 반복 실행해 거리별 탐지율을 비교해야 한다.

현재 접근 제어는 시뮬레이터의 과녁 월드 좌표를 사용한다. YOLO 탐지 결과는 기체 이동 명령에 반영되지 않으므로, 이 시험은 영상 기반 유도 성능을 평가하지 않는다. HEF의 양자화·후처리 효과를 확인하려면 실제 Hailo-8 장치에서 같은 프레임으로 별도 검증해야 한다.
